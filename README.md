# 接龙小作家 · 越读越会写（Next Word Wizard）

> 我说上半句，你接下半句——把 GPT-3 的大力出奇迹变成孩子的接龙游戏。

![封面](cover.jpg)

## 这是什么？

「和孩子一起学AI」社群 **AI十哲系列 · 第九课** 的配套游戏，把 2020 年 OpenAI 的经典模型 **GPT-3** 变成孩子能上手玩的接龙挑战：

- 🐲 **顺口接龙**：我说上半句，你接下半句——哪个词被接得最多？
- ⚡ **举一反三**：没人教规则，看两个例子就能猜出第三个
- 🔍 **胡说八道探测器**：三句话里有一句是 AI 一本正经编的——抓出它！

## 怎么玩？

1. 双击打开 `index.html`（手机、电脑都行，无需联网）
2. 看句子或例子，从三个候选里选出正确答案
3. 三大关卡层层升级：

- 🐲 **顺口接龙**：日常句子接下一句——凭语感就能赢，小心「读着通但其实错了」的陷阱词
- ⚡ **举一反三**：苹果→水果，白菜→蔬菜，西瓜→？照样子推规律
- 🔍 **胡说八道探测器**：AI 说得越自信，越要当心——自信 ≠ 正确！

4. 集齐三枚徽章 🐲⚡🔍，领取「**GPT 大力小作家证书**」，截图发群里领奖状！

## 教育目标

- 理解 GPT-3 的核心直觉：**读得够多，就会接**（预测下一个词的儿童版表达）；练习量堆到一定程度，本事会「突然冒出来」（涌现）
- 体验「举一反三」：不给规则、只给例子，AI 就能照样子做——这是未来最重要的提问技能
- 媒介素养：AI 会用最自信的口气说错话——**自信 ≠ 正确，出处呢？**
- 迁移到学习：「读书破万卷，下笔如有神」——孩子的阅读量，就是孩子的「参数」
